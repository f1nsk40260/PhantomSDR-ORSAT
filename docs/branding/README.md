# Identité visuelle d'ORSAT

| Fichier | Usage |
|---|---|
| `orsat-icon.svg` | Logo vectoriel (source de toutes les autres images) |
| `orsat-icon-512.png` | Logo en PNG, 512 × 512 |
| `orsat-banner.png` | Bandeau du README GitHub |
| `facebook-profil.png` | Photo de profil de la page Facebook (720 × 720) |
| `facebook-couverture.png` | Photo de couverture Facebook (1640 × 624) |

Les icônes du navigateur sont dans `frontend/public/` (`orsat-icon.svg`,
`orsat-icon-32.png`, `orsat-icon-192.png`, `orsat-icon-512.png`,
`apple-touch-icon.png`) et `frontend/favicon.ico`, copié dans `dist/` à chaque
compilation.
